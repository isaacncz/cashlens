# Inter

`inter-latin-variable.woff2` is the Latin variable weight font from the Inter project, distributed through Fontsource's CDN. Retrieved 27 October 2026 from:

https://cdn.jsdelivr.net/fontsource/fonts/inter:vf@latest/latin-wght-normal.woff2

SIL Open Font License 1.1: `Inter-OFL.txt`, sourced from the Google Fonts Inter distribution:

https://raw.githubusercontent.com/google/fonts/main/ofl/inter/OFL.txt

The app self-hosts this 48,256-byte font, preloads it locally, and uses `font-display: optional` to avoid a late layout shift. There are no runtime font-service requests and no package dependency.
